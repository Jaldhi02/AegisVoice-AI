# AI Integration Guide — Connecting ML Models to Backend

This guide outlines how **Om (AI/ML Engineer)** can seamlessly plug PyTorch, TensorFlow, Whisper, Wav2Vec2, or custom NLP transformer models into the **FastAPI Backend** without altering API routers or database logic.

---

## 1. Overview of `ai/inference/` Structure

The backend imports machine learning detection logic from the `ai/inference/` package located at the repository root:

```
ai-voice-fraud-detector/
└── ai/
    └── inference/
        ├── __init__.py
        ├── voice_detector.py      ← Deepfake audio detection
        ├── scam_detector.py       ← Speech-to-Text & Scam NLP analysis
        └── risk_engine.py         ← Composite risk scoring & heuristics
```

Because the FastAPI routers invoke functions from `ai.inference.*`, updating the backend to use your trained ML models requires only replacing the function internals while matching the declared Python function signatures.

## 2. Voice Clone Detector Contract (`ai/inference/voice_detector.py`)

### Required Signature
```python
def analyze_voice(audio_path: str) -> dict:
    """
    Analyzes an audio file for synthetic or cloned voice signatures.
    
    Parameters:
        audio_path (str): Absolute file path to the uploaded .wav, .mp3, or .m4a file.
        
    Returns:
        dict: {
            "voice_status": "REAL" | "AI_GENERATED" | "UNKNOWN",
            "voice_confidence": float (0.0 to 1.0),
            "reasons": list[str]
        }
    """
```

### Integration Example (PyTorch / Wav2Vec2)
```python
import torch
import torchaudio

# Load your fine-tuned deepfake detector model
# MODEL = load_voice_model("path/to/weights.pth")

def analyze_voice(audio_path: str) -> dict:
    try:
        waveform, sample_rate = torchaudio.load(audio_path)
        # Process waveform through your neural net
        # confidence = MODEL.predict(waveform)
        confidence = 0.94  # Example score
        
        is_ai = confidence > 0.65
        status = "AI_GENERATED" if is_ai else "REAL"
        
        reasons = []
        if is_ai:
            reasons.append("High neural artifact probability in spectral domain")
        else:
            reasons.append("Natural acoustic pitch variance observed")
            
        return {
            "voice_status": status,
            "voice_confidence": round(float(confidence), 2),
            "reasons": reasons
        }
    except Exception as e:
        return {
            "voice_status": "UNKNOWN",
            "voice_confidence": 0.0,
            "reasons": [f"Voice detection error: {str(e)}"]
        }
```

## 3. Scam NLP Engine Contract (`ai/inference/scam_detector.py`)

### Required Signature
```python
def analyze_scam(text: str) -> dict:
    """
    Analyzes a speech transcript for fraud/scam indicators.
    
    Parameters:
        text (str): Speech transcript generated by ASR (Whisper/DeepSpeech).
        
    Returns:
        dict: {
            "transcript": str,
            "scam_detected": bool,
            "scam_confidence": float (0.0 to 1.0),
            "reasons": list[str]
        }
    """
```

### Integration Example (Transformers / BERT)
```python
from transformers import pipeline

# SCAM_CLASSIFIER = pipeline("text-classification", model="your-scam-bert-model")

def analyze_scam(text: str) -> dict:
    if not text or len(text.strip()) == 0:
        return {
            "transcript": "",
            "scam_detected": False,
            "scam_confidence": 0.0,
            "reasons": ["Empty transcript provided"]
        }

    # Example keyword and model processing
    # result = SCAM_CLASSIFIER(text)
    
    keywords = ["otp", "password", "bank", "compromised", "urgent", "police"]
    found = [kw for kw in keywords if kw in text.lower()]
    
    scam_detected = len(found) > 0
    confidence = min(0.5 + (len(found) * 0.2), 0.98) if scam_detected else 0.05
    
    reasons = [f"Fraud keyword pattern found: '{kw}'" for kw in found]
    if not reasons:
        reasons.append("No scam indicators detected in text")
        
    return {
        "transcript": text,
        "scam_detected": scam_detected,
        "scam_confidence": round(float(confidence), 2),
        "reasons": reasons
    }
```

## 5. Hot-Swapping ML Weights Checklist

1. Place model weights in an `ai/models/` directory or download them on startup.
2. Load heavy models lazily or inside module-level singletons so they load once when the FastAPI server boots.
3. Ensure function signatures match the types specified above.
4. Run `pytest backend/tests/test_analysis.py -v` to confirm the backend integration tests pass.
